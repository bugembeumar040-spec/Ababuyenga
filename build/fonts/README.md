Fonts are not committed. Fetch before rendering:

    curl -sSO https://raw.githubusercontent.com/google/fonts/main/ofl/anton/Anton-Regular.ttf
    curl -sS -o ArchivoNarrow-Bold.ttf \
      "https://raw.githubusercontent.com/google/fonts/main/ofl/archivonarrow/ArchivoNarrow%5Bwght%5D.ttf"

Anton (SIL OFL) sets CAP1 and the burn-ins; Archivo Narrow (SIL OFL, variable,
used at weight 620-700) sets CAP2 and the small tracked labels.
